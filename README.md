# Dynamic Island для Android

Приложение показывает меню с демонстрацией применения настроек, затем запускает настоящее системное overlay-окно поверх других приложений. Демонстрация не выполняет джейлбрейк. Android просит пользователя явно выдать разрешение «Показывать поверх других приложений». Удержание небольшой плашки увеличивает её; после отпускания она возвращается к обычному размеру. Кнопка в постоянном уведомлении выключает сервис.

Файл `index.html` — только экран управления. Сам островок создаётся нативным Android `WindowManager` в foreground service.

## Сборка через GitHub Actions

Файл `.github/workflows/build.yml` запускает сборку при push и вручную. После успешного запуска скачайте артефакт `DynamicIsland-APK`; внутри будет `app-debug.apk`.

Это debug APK для установки на собственное устройство. При первом включении нужно разрешить показ поверх других приложений в системных настройках Android.
